# 1 Bell

A 20–30 minute workout app for one 30 lb kettlebell, with a 3D coach, rotating workouts and a workout calendar. People sign in with an email code, and each person sees only their own schedule and history. You can install it on a phone's home screen, and it works offline.

- **Deploy it:** follow [`SETUP.md`](SETUP.md) (Supabase + GitHub Pages + phone install).
- **Run it locally:** `powershell -File .claude/serve.ps1 8000`, then open http://localhost:8000.
- **How the code is organized:** see [`CLAUDE.md`](CLAUDE.md).
